Interview prep

Read it as a website: https://skalvinnathan.github.io/interview-prep/

Short on time? Start with the three-day crash plan.

Plain-English study notes for platform, backend and software engineer interviews, written for people who want every term explained from zero.

  • Code in 01-dsa and 03-low-level-design was run (Python 3.9) before being written down.
  • Claims about specific companies are labelled Official, Third-party, Anecdotal or General advice inside each file. Company hiring processes change: check official pages before relying on any of it.
  • Sample command output is from a Mac unless marked [SAMPLE].
